## 范围与原则

- 保持后端、接口、共享领域类型、金额计算、权限及支付流程不变。
- 已获确认：lucide-react、现有页面/组件样式及交互调整；未开发功能暂缓。
- 主 Agent 写计划/验收，H5、Admin、Site Agent 在各自领地实现；保留已有改动。
- pnpm 安装产生的锁文件变更为依赖安装的机械产物，不手工改其他依赖。
- Stitch 截图/HTML 为设计依据，现有演示稿仅辅助；真实数据优先，不复制图片中的身份/统计值作为业务事实。
- 同视口/同状态截图验收，构建通过不等于视觉或交互通过。

## 分步实施

### A. 基线

1. 获取截图与 HTML，记录屏幕 ID/尺寸/路由；网络失败如实登记。
2. 对照 tokens：珊瑚主色、青绿辅色、状态色、字体、圆角、间距、阴影。
3. 复用 SchemaRenderer、ProductCard 适配层、useDebounceAction、领域 hooks、formatPrice，不另造领域类型。

### B. H5 浏览与登录

1. 安装已批准的图标库，统一底栏/按钮图标、选中态和安全区。
2. 首页实图、轮播、分类及商品分区按设计对齐；真实 API 图片优先，演示图片只用于演示数据。
3. 分类、搜索、登录、详情/SKU 按设计调整结构与状态。
4. 检查 375/390/430 宽度、44px 点击区、长标题、断图、加载与空态。

### C. H5 交易及账户

1. 统一购物车、确认订单、支付、订单、账户、消息、售后组件。
2. 保留真实调用、防重复提交及错误时的用户输入。
3. 改正假成功、死按钮，不将未开发能力伪装为可用。

### D. Admin

1. 修正虚构身份、固定日期、无效通知入口；保留全部真实导航。
2. 对齐看板、商品规格、订单、售后/会员、搭建器。
3. 统一控件、表格密度、分页/标签、空态、弹窗、主次动作。
4. 检查 1280/1440 宽度、表格滚动、弹层键盘及忙碌/错误状态。

### E. 3D

现状：共享包只有配置、能力降级与速度工具；Site 使用 CSS 动画环和“360°”占位，没有模型渲染、旋转或缩放。

现有展示直接修正：

1. reduced-motion 变化时重新计算所有能力条件，避免覆盖移动端/低内存限制。
2. 视口变化重算，卸载清理监听器。
3. 无真实渲染器时优先显示静态回退图；缺素材用诚实空态，不暗示可拖动。
4. 减少动画、离屏、隐藏页面暂停装饰动画；不拦截滚动。

完整 3D 需先形成具体提案再确认：

- 查 React 18 兼容的 Three/R3F/drei；PRD 的 R3F 9.x 与 React 18 可能冲突，不擅自升级框架。
- Hero 几何/粒子场景与商品 GLB 分别验收；没有模型时不拿任意模型冒充商品。
- 加载/失败/重试、WebGL 降级、拖动旋转、缩放/复位、键盘替代、触屏不抢滚动。
- 视口懒加载、DPR 1–2、按需渲染、隐藏暂停、GPU/事件清理，单模型目标 ≤2MB。
- 默认官网目前无 3D 板块，新增展示位置也需确认。

### 完整 3D 的待确认实施方案

| 项目 | 提案 | 验收 |
|---|---|---|
| 依赖 | 保持 React 18；候选 `three` + React 18 兼容的 R3F 8 / drei 9。安装前核对实际 peerDependencies，不升级全仓 React；PRD 的 R3F 9 / drei 10 组合先不采用 | peer 无冲突；H5/Admin 默认依赖图无 Three |
| 展示位置 | 官网既有 Hero 旁的可选视觉区域，文本/CTA 保持；后台仅沿已有 Schema 入口配置。默认配置是否开启需确认 | 可关闭；移动端仍有完整内容和 CTA |
| Hero 首批 | 使用代码生成的浮动几何场景，按项目珊瑚/青绿 token 控制材质；缓慢运动、轻微指针反馈，不拿抽象模型冒充商品 | 静态首帧、暂停/减少动画、视口外停止，滚动不被拦截 |
| 商品查看器 | 仅在有真实 GLB/GLTF 与预览图时启用；拖动旋转、缩放、复位与键盘替代。不制造任意商品模型 | 模型加载成功/失败/重试、触屏滚动、键盘、资源卸载 |
| 预算 | 可见时加载独立 chunk，DPR 上限 2；模型目标 ≤2MB；无交互时按需渲染，页面隐藏时暂停 | 比较加载请求、主线程/GPU占用及前后构建图；没有测量不宣称性能提升百分比 |
| 未纳入首批 | 模型上传、热点编辑、WebGPU 专用管线、六种场景编辑器 | 按未开发功能另行对照需求确认 |

2026-09-19 用户明确批准首批方案：保持 React 18、安装兼容 Three/R3F 依赖、官网 Hero 可关闭的浮动几何场景；商品模型另行提供。无需重复确认这些动作。商品查看器在真实模型到位前保留静态图。网络/依赖执行限制如实登记，不用未验证依赖冒充完成。

## 验收

- 各实施 Agent 实跑 typecheck/lint/test/build，主 Agent 按 5+1 复核并独立复跑。
- 检查改动范围、依赖、代表实现、类型/构建、重复代码。
- 真实浏览器检查并记录视口、路由、数据模式与交互状态；至少覆盖首页、分类、登录、详情/SKU、购物车、后台看板/商品/订单/搭建器。
- 操作检查：导航、轮播、规格、忙碌禁用、表单错误、焦点、弹层关闭/恢复、reduced-motion。
- 服务/数据不足的项目标为未验收，不声称已通过端到端。
