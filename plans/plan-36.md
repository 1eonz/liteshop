# Plan 36：H5 交易与个人中心体验补齐

> PRD 章节：4.1.2+4.1.3+4.1.4+4.1.5+D6.1+D6.2+D6.7+E15
> 当前状态：待开始

## 目标

补齐不依赖第三方供应商的 H5 交易反馈、搜索、地址、通知和个人中心体验。

## 任务清单

- [ ] 增加独立搜索页、搜索历史、热门搜索和结果筛选；历史记录绑定用户并支持清理。
- [ ] 支付页增加基于订单过期时间的倒计时，时间到后刷新订单状态并禁用支付。
- [ ] 订单详情增加语义化状态步骤条、提醒发货入口和允许场景下的售后入口。
- [ ] “我的”页增加通知、客服、设置入口和订单状态角标；路由集中配置。
- [ ] 通知中心补未读计数；SSE 如需新增服务端契约，先完成契约确认，否则保留轮询降级。
- [ ] 地址表单改为省市区级联选择，保存编码与展示文本，不再要求用户手输编码。
- [ ] 增加评价提交入口、浏览足迹和相关推荐消费；复用既有评价/商品服务。
- [ ] 加购动画遵守 reduced motion，不遮挡按钮、不影响点击和布局稳定。
- [ ] 所有写操作使用 `useDebounceAction`，mutation `retry: 0`，失败有恢复路径。
- [ ] 补支付过期、搜索历史隔离、通知角标、地址选择、评价提交和键盘/触摸测试。

## 验收标准

- [ ] 交易关键状态可理解、可恢复，不因倒计时或动画产生重复支付/重复提交。
- [ ] 个人中心所有已注册路由都有可发现入口，空状态和错误状态完整。
- [ ] 所有文本、视觉值和交互状态遵循项目 i18n、Design Tokens 与 a11y 约束。
