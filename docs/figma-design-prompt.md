# LiteShop Figma 设计提示词

下面的内容可直接粘贴到 Figma Make、Figma AI 或交给设计师作为首轮设计 brief。它以当前仓库中的 `packages/h5-app` 与 `packages/admin-app` 代码为准，不引入尚未实现的业务功能。

```text
你正在为 LiteShop 轻量级低代码商城系统创建一套可交付、可开发、可演示的 Figma UI 设计。请把下面的代码事实视为唯一业务范围，保留页面名称、中文文案、路由关系和交互状态，不要自行增加会员、优惠券、评价、售后、通知中心、低代码搭建器等当前代码中没有的功能。

一、输出结构

请在同一个 Figma 文件中建立以下页面（Starter 计划限制为 3 个页面，因此组件与原型板嵌入对应产品页）：

1. `00 Foundations`：颜色、字体、字号、间距、圆角、阴影、图标、状态和响应式标注。
2. `01 H5 App`：375 x 812 的移动端页面，全部页面按 8pt 网格对齐；把 H5 组件状态、核心购买流程和各路由画板放在本页不同区域；额外提供 320 x 812 和 430 x 932 的适配检查画板。
3. `02 Admin App`：1440 x 1024 的桌面后台页面；把 Admin 组件状态、后台运营流程和各路由画板放在本页不同区域；同时标注 1280px 为最小工作宽度，低于该宽度允许横向滚动，不做移动端重排。

所有重复 UI 必须做成 Figma Component，并用 Variants 表达状态；不要把重复元素做成互不关联的临时图层。使用 Auto Layout、Constraints、Layout Grid 和 Variables，确保设计可以直接交给 React 开发。

二、品牌与 Design Tokens

产品气质：现代、简洁、亲和、可信。H5 偏生活方式和转化，Admin 偏高效、密集、专业。避免营销落地页风格、过度插画、霓虹色、紫色渐变、厚重阴影和嵌套卡片。

颜色请建立 Figma Variables，不要在页面中散落硬编码颜色：

- 品牌主色：`#ff6b6b`；hover `#e54545`；active/深色文字 `#c93030`；浅色背景 `#fff1f1`、`#ffe0e0`。
- 成功：`#52c41a`，警告：`#faad14`，错误：`#ff4d4f`，信息：`#1890ff`。
- 主文字：`#203236`；辅助文字：`#718083`；页面背景：`#f5f7f7`；卡片背景：`#ffffff`；分割线：`#e6eeee`。
- H5 辅助青绿色：`#4ecdc4` / `#2cb9b0`，用于活动横幅、立即购买和成功状态。
- 商品占位背景使用低饱和的暖白、浅蓝、灰青、浅紫色块；不要绘制虚假的具体商品摄影，图片区域应明确标注为可替换图片资源。

字体使用系统中文字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`；价格和统计数字使用等宽数字风格。H5 正文 14-16px，页面标题 20-24px，Hero 标题 32px；Admin 正文 13-14px，页面标题 28-32px，表格行高 48px。

间距只使用 4/8/12/16/20/24/32/48/64/80/96px token。H5 卡片圆角 12px，按钮和输入框 8px；Admin 卡片/按钮 6px、输入框 4px。H5 卡片使用轻阴影，Admin 默认无阴影，仅 hover 使用轻阴影。焦点环使用 3px 高对比度珊瑚红外框。

图标统一使用 Lucide 风格，按钮中的图标为 16px，导航为 24px，空状态为 64px；不要用文字字符模拟箭头、关闭、加减、收藏、首页等图标。

三、H5 App 页面与组件

H5 使用 375px 手机画板，内容最大宽度 375px，顶部和底部考虑安全区域。页面背景为 `#f5f7f7`，主内容卡片白色。顶部导航和底部操作栏使用半透明白色毛玻璃，但保证文字和按钮对比度。

共享 H5 组件：

- `H5/Header`：sticky 顶部栏，LiteShop 品牌字样 + 胶囊搜索框；搜索框包含占位符“搜索商品”和可见的清除按钮状态。
- `H5/BottomTabBar`：四项“首页 / 分类 / 购物车 / 我的”，图标 24px，选中为主色，未选中为灰色，顶部 1px 分割线，底部留出 safe-area。
- `H5/ProductCard`：1:1 图片、单行商品名、价格、销量；价格使用数字字体和主色，卡片不放多余按钮。
- `H5/SectionTitle`、`H5/Feedback`、`H5/EmptyState`、`H5/AddressCard`、`H5/OrderCard`、`H5/CartItem`、`H5/SkuDrawer`、`H5/CheckoutBar`。

请制作以下页面，并在每个页面旁边补齐 Loading、Error、Empty、Disabled/Loading、Success 状态：

1. 首页 `/`
   - sticky Header：LiteShop + 搜索商品。
   - Hero 轮播，三张文案必须使用：
     `今日精选 / 把喜欢的生活带回家 / 精选日常好物，今天下单更快送达 / 探索好物`；
     `通勤提案 / 轻装出发，也要有好心情 / 从一只保温杯开始，整理你的日常节奏 / 看看保温杯`；
     `春日上新 / 给家里添一点柔和光线 / 精选小物限时优惠，慢慢布置喜欢的空间 / 浏览人气好物`。
     Hero 下方有左右切换、圆点指示和主按钮。
   - “热门分类”八项：新品、家居、服饰、数码、美妆、食品、运动、礼物，4 列网格。
   - 青绿色“限时活动”横幅：`春日好物 / 低至 7 折 / 去看看`。
   - “人气好物”双列商品网格；搜索后标题变为“搜索结果”，显示结果数量。

2. 分类 `/categories`
   - 返回箭头 + 标题“商品分类”。
   - 可横向滚动的胶囊 Tab：全部及分类名称，选中态为浅珊瑚背景。
   - “精选好物 / 发现适合你的生活好物 / 按分类浏览，快速找到今天想要的东西。”和双列商品网格。

3. 商品详情 `/product/:productId`
   - 返回、1:1 或大比例商品视觉区、左右切换、三点轮播。
   - 商品名、商品副标题、价格；“选择规格”区显示规格和库存。
   - “商品详情”区，右侧有“收藏商品/已收藏”状态。
   - 底部固定操作栏：`选择规格`、`加入购物车`、`立即购买`。
   - 点击规格打开底部 Sheet：拖拽条、标题“选择规格”、关闭图标、规格列表、价格、选中态和全宽“确定”按钮；遮罩覆盖页面。

4. 购物车 `/cart`
   - 返回 + “购物车”；全选、商品数量。
   - CartItem 包含复选框、图片、商品名、SKU 编码、单价、数量步进器、删除图标。
   - 空状态文案：`购物车还是空的 / 去挑几件喜欢的好物吧 / 去逛逛`。
   - 底部固定结算栏显示“合计”金额和“去结算”；未选择商品时按钮禁用。

5. 确认订单 `/order/confirm`
   - 地址卡片：收货人、脱敏手机号、详细地址、默认地址入口。
   - “商品清单”、订单备注输入框、商品金额、运费（计算中/包邮/失败）。
   - 底部固定栏显示“应付”总额和“提交订单”。
   - 提交成功态：成功图标、`订单已提交`、`感谢你的选择，我们会尽快为你准备商品。`、`继续逛逛`。

6. 收银台 `/payment/:orderId`
   - 订单号、应付金额、微信支付/支付宝二选一卡片。
   - 主按钮文案根据渠道切换：`使用微信支付` / `使用支付宝支付`。
   - 支付单创建成功态、失败态和返回订单按钮。

7. 我的订单 `/orders` 与订单详情 `/orders/:orderId`
   - 订单卡片显示订单号、状态（待付款/待发货/配送中/已完成/已取消）、商品摘要、日期、总额。
   - 详情页显示订单状态卡、收货地址、商品清单、商品金额、运费、合计、物流单号和操作按钮。

8. 我的 `/me`
   - 未登录：空状态、`登录后管理你的订单`、同步说明、`去登录`。
   - 已登录：珊瑚红到青绿色的个人信息头部、圆形 L 头像、昵称/手机号；入口为“我的订单 / 收货地址 / 我的收藏”；底部“退出登录”。

9. 收货地址 `/addresses`
   - 地址列表、默认标签、编辑/删除文字操作。
   - 新增/编辑地址表单：收货人、手机号、省份编码、城市编码、区县编码、详细地址、设为默认地址、保存地址。

10. 我的收藏 `/favorites`：双列 ProductCard；空状态 `还没有收藏 / 去发现好物`。
11. 登录 `/login`：`登录 LiteShop`、`手机号登录`、`欢迎回来`、手机号输入、6 位验证码、获取验证码、登录按钮和错误反馈。

H5 交互原型：搜索提交更新商品标题和数量；Hero 与商品图轮播可点击切换；商品卡进入详情；规格按钮打开/关闭底部 Sheet；收藏、加购、数量调整、删除、去结算、提交订单、支付渠道切换、底部 Tab 路由全部可点击。所有写操作必须有默认、hover/pressed、loading/disabled、error 和 success 状态；loading 状态禁止重复点击。

四、Admin App 页面与组件

Admin 使用桌面工作台布局：左侧固定 220px 导航，右侧内容最大宽度 1180px，页面背景 `#f5f7f7`。后台默认无大面积阴影，信息密度高但保留 16/24px 呼吸空间。导航项精确使用：数据看板、商品管理、商品列表、分类管理、订单管理、库存管理、系统设置、审计与权限；当前项为浅珊瑚背景和主色文字。

共享 Admin 组件：

- `Admin/Shell`、`Admin/Sidebar`、`Admin/PageHeader`、`Admin/MetricCard`、`Admin/Panel`、`Admin/Toolbar`、`Admin/TableRow`、`Admin/StatusBadge`、`Admin/InlineForm`、`Admin/Feedback`、`Admin/EmptyState`、`Admin/Chart`。
- 按钮尺寸 44px 高；表格单元格 8px 12px；状态标签使用成功/警告/错误色，不依赖颜色 alone，必须同时显示文字。

请制作以下页面，并补齐表格 hover、按钮 loading/disabled、空数据、错误和成功反馈：

1. 登录 `/login`
   - 居中白色表单面板，`LiteShop Admin`、`管理员登录`、手机号、验证码、`进入后台`；错误反馈使用错误色块。

2. 数据看板 `/`
   - 页面标题区：`运营中心 / 数据看板`，右侧 `导出报表`。
   - 四个指标卡：今日销售额、支付订单、在售商品、待发货；数字突出，辅助信息分别为实时聚合、累计订单、商品总量、需处理/已清空。
   - Panel“销售趋势”，近 7 天折线图；使用五色图表 token，主系列珊瑚红，网格和文字使用中性色。
   - Panel“商品排行”，按销量列出排名、商品名、销量。
   - Panel“待办提醒”，待发货订单、低库存 SKU、待审计事项三项。

3. 商品列表 `/products`
   - `商品中心 / 商品管理`、主按钮 `新建商品`。
   - 搜索商品工具栏、名称关键词输入、刷新、结果数量。
   - 列表行显示商品名、状态（草稿/已上架/已下架）、价格区间、销量和进入编辑箭头。

4. 新建/编辑商品 `/products/edit`、`/products/edit/:productId`
   - 页面头部 `新建商品` 或 `编辑商品`、`保存商品`。
   - 表单字段：商品名称、品牌、副标题、商品描述、发布状态。
   - 新建时增加“首个 SKU”：SKU 编码、SKU 名称、价格（分）、实物库存；明确标注金额单位为整数分。
   - “SKU 规格”表格：规格、编码、价格（分）、可售库存；底部显示已保存、错误和保存中状态。

5. 分类管理 `/categories`
   - `商品中心 / 分类管理`、新增分类输入和 `新增分类`。
   - 分类列表显示名称、排序、`重命名` 和 `停用`。

6. 订单管理 `/orders`
   - `订单管理 / 订单列表`、刷新按钮、错误提示。
   - 每行显示订单号、状态、商品摘要、金额和操作。
   - PAID 状态可展开物流单号输入和 `确认发货`；PENDING_PAYMENT 可 `取消`；支持 `备注/改价` 的行内编辑。

7. 库存管理 `/inventory`
   - `库存管理 / 库存台账`、刷新按钮。
   - 表格列：SKU、实物库存、可售库存、锁定库存、操作；低库存显示“低库存”警告标签。
   - 行内“调整”表单包含 ± 数量、原因、保存、取消；“流水”打开 Panel，显示事件类型、数量、原因/引用单号、时间。

8. 系统设置 `/settings`
   - `系统设置 / 基础设置`、保存设置。
   - 商城名称、订单超时取消（分钟）、主题主色、导航样式（毛玻璃/纯色）、Tabbar 样式（画廊/极简）、支付沙箱开关。
   - 下方“功能开关”列表显示服务端状态；保存成功显示绿色成功反馈。

9. 审计与权限 `/audit`
   - `安全与权限 / 操作审计`。
   - “角色权限”Panel 显示角色、权限和权限点数量；“最近操作”Panel 显示操作、资源、时间、requestId。

Admin 交互原型：侧边栏 NavLink 切换页面；刷新、导出报表、保存、发货、取消、改价、库存调整、分类新增/停用、设置保存都要有 loading 和禁用状态；订单发货与改价使用行内展开，不要跳出到虚构页面；图表只做可读的静态演示，不新增筛选维度。

五、可访问性与交付要求

- 使用语义化层级和真实按钮/链接；所有图标按钮有 tooltip 和 aria-label；键盘 Tab 顺序可用，焦点环清晰。
- 正文、辅助文字、状态标签满足 WCAG AA 对比度；不要只用颜色表达状态。
- 所有页面提供 Loading、Error、Empty、Success 变体；错误反馈与操作结果靠近触发点。
- 所有写操作按钮的 loading 状态必须显示“处理中/保存中/提交中”等文字并 disabled。
- H5 触控目标至少 44 x 44px；后台表格在 1280px 宽度仍能完整阅读。
- 原型必须覆盖：H5 首页 -> 商品详情 -> 规格 Sheet -> 加入购物车 -> 购物车 -> 确认订单 -> 提交成功，以及 Admin 登录 -> 数据看板 -> 商品列表 -> 商品编辑 -> 订单发货 -> 库存流水。
- 最终交付应包含可开发标注：画板尺寸、组件尺寸、间距 token、颜色变量、文字样式、圆角/阴影变量、状态命名和原型连接。不要生成与当前代码不一致的新页面或新业务字段。
```

## 使用方式

当前目标文件已经建立三页：`00 Foundations`、`01 H5 App`、`02 Admin App`。Starter 计划最多 3 页，因此组件状态与核心流程以画板形式嵌入 H5/Admin 页面，不再创建独立的 `03 Components`、`04 Prototype` 页面。已落地的画板包括：`H5 Home - 375 x 812`、`Core flow - Product to checkout`、`Components - H5 states`、`Admin Dashboard - 1440 x 1024`、`Operations - Product and Order Management`。

继续补图时，请在对应页面右侧按“页面与组件”章节追加路由画板，并沿用已有节点的颜色变量、字体、圆角、间距和命名；不要新建页面。生成后用当前代码逐页对照，重点检查中文文案、路由顺序、底部固定栏、后台 220px 侧栏、Loading/Empty/Error 状态是否齐全。
