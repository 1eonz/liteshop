## 资料分级

- 核心：上表中的当前交接、架构、验证、PRD、契约、设计、AGENTS。
- 专题：CI/CD、API 版本、可观测性、环境与 Skills 指南；只在对应任务需要时阅读。
- 参考：HTML 设计演示、Figma 提示词、根目录的早期分析/UI Kit 方案；它们不是当前功能完成的证据。
- 历史：`archive/阶段交接历史.md` 保留旧阶段报告；旧命令结果只对当时版本成立。

## 维护规则

1. 功能需求改 PRD，接口改 OpenAPI，设计改设计规范；不要复制到新的“总方案”。
2. 当前交接只记录现在的结果和下一步；历史过程留给 Git 与已有历史记录。
3. 一次重构在现有计划中更新结果，不再新增多份验收/复盘/总结文档。
4. 不能用演示数据、静态占位或旧测试数字证明真实业务可用。
