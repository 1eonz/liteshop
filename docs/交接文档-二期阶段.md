# LiteShop 二期交接文档

> 交接版本：二期官网基础能力与三期 3D 基础工具
>
> 记录日期：2026-09-06

## 已完成

- `packages/site-app` 已从最小占位页升级为 App Router 官网：首页、`/about`、`/products`、`/contact` 动态页面、静态参数、Metadata、sitemap、robots 和 404。
- 官网 Schema 数据与渲染器已建立，覆盖导航、Footer、Hero、HeroSplit、Features、Stats、LogoWall、Testimonials、Pricing、FAQ、图文、CTA、联系表单及 3D 占位等 18 类组件。
- 官网视觉复用 `shared-tokens` 和画廊风格变量，响应式覆盖 320px，支持移动端导航抽屉、表单提交状态、键盘焦点和减少动画偏好。
- 联系表单后端新增 DTO、Service、Repository、幂等 API 与 PostgreSQL `form_submissions` 迁移；开发模式内存存储，数据库模式真实落库。
- `shared-3d-components` 新增场景预设、速度限制和设备降级工具，暂不引入 Three.js/R3F。

## 验证

- 官网 `typecheck`、`lint`、`test`、`next build` 全部通过，生成 `/`、`/about`、`/products`、`/contact`、sitemap、robots 和 404。
- Backend Ruff、mypy、35 条 pytest 全部通过；真实 PostgreSQL 联系表单写入通过。
- shared-3d-components 构建与 3 条工具测试通过。

## 未完成与阻塞

- 官网页面目前使用本地 Schema 数据，尚未从后台页面 API 读取，也未接入 ISR revalidate webhook。
- 导航菜单、Footer 配置、官网全局设置和页面 SEO 字段尚未落库；联系表单后台查询、邮件/企微通知和更严格限流待补。
- 商城低代码编辑器仍缺模板、预览、A/B 变体和完整 10 组件扩展。
- Three.js/R3F/drei、GSAP、Lenis、Framer Motion 尚未接入。它们属于新增依赖，按 AGENTS.md 需先确认依赖与包体积预算；当前使用 CSS/原生降级实现，不阻塞官网构建。
- 三期多租户、优惠券/拼团/分销、物流轨迹、AI 文案和智能补货尚未实现，需要独立数据模型与基础设施决策。

## 下一步

2. 完成 plan-29：商城搭建器持久化、模板、预览、A/B 变体和相关推荐。
3. 补官网 API/ISR、联系表单后台处理与集成 E2E。

## 规避事项

- 不在页面组件内散落 API 请求；官网数据通过 Schema/feature 层进入渲染器。
- 不把 CSS 颜色、间距、圆角和阴影写成业务常量，统一使用 Token。
- 新增 3D/动画依赖前先记录依赖决策、首屏体积和降级策略。
- 联系表单写入必须带请求 ID，重复提交返回原结果，不能依赖前端按钮禁用作为唯一防线。
