# LiteShop 设计规范（Design System）

> 本文件是 LiteShop 全端（H5 商城 / 管理后台 / 官网 / 共享组件）的统一视觉规范。
> 所有 Agent 在写 UI 时必须遵循本规范。本规范作为 PRD 附录 D1.6 的扩展，与 PRD 配套使用。
> 配套：`packages/shared-tokens/`（实现层）、Storybook（可视化文档）

---

## 一、设计理念

### 1.1 产品定位

LiteShop 是面向中小商家的轻量级低代码商城系统。视觉风格应该：

- **现代简洁**：不堆砌装饰，留白充足，信息密度适中
- **商家友好**：后台高效操作，H5 信任感强，官网专业感
- **可配置**：商家能通过主题配置快速换色，不需要改代码
- **跨端一致**：H5 / 官网 / 后台共享同一套 Design Tokens，品牌感统一

### 1.2 三端视觉差异

| 维度 | H5 商城 | 管理后台 | 官网 |
|---|---|---|---|
| 风格 | 活泼、信任、转化导向 | 高效、密集、专业 | 大气、叙事、品牌感 |
| 主色 | 主色 #ff6b6b（珊瑚红） | 同主色 | 同主色 |
| 字号 | 偏大（移动端阅读） | 偏小（信息密集） | 中等 + Hero 大字号 |
| 间距 | 紧凑（屏幕有限） | 紧凑 | 宽松（叙事空间） |
| 圆角 | 8px（亲和） | 6px（专业） | 12px（现代） |
| 阴影 | 轻柔 | 几乎不用 | Hero 区用明显阴影 |
| 动效 | 转场过渡，不过度 | 无（效率优先） | 滚动动画 + Hero 视差 |

## 二、色彩系统

### 2.1 品牌主色

主色 `#ff6b6b`（珊瑚红），传达热情、活力、消费欲望。生成 11 级色阶：

```css
:root {
  --color-primary-50:  #fff1f1;   /* 最浅，背景/禁用态 */
  --color-primary-100: #ffe0e0;
  --color-primary-200: #ffc6c6;
  --color-primary-300: #ffa3a3;
  --color-primary-400: #ff8080;
  --color-primary-500: #ff6b6b;   /* 主色，按钮/链接/选中态 */
  --color-primary-600: #e54545;   /* hover */
  --color-primary-700: #c93030;   /* active */
  --color-primary-800: #a82828;
  --color-primary-900: #8a2020;   /* 最深 */
  --color-primary: var(--color-primary-500);  /* 别名 */
}
```

**使用场景**：
- 500：主按钮、链接、选中态、Tabbar 选中
- 600：主按钮 hover
- 700：主按钮 active
- 50：主色背景（如优惠券标签底色）、禁用态背景

### 2.6 图表色板（数据可视化专用）

后台数据看板（§14.2）与所有 ECharts 图表统一用本色板，**禁硬编码 hex**。其中 1~4 号取自功能色/主色，5 号紫为数据可视化专用补充色（UI 界面禁用紫色，仅图表第 5 系列可用）：

```css
:root {
  --chart-color-1: #ff6b6b;   /* 主数据系列（= 主色 primary-500） */
  --chart-color-2: #1890ff;   /* 次数据系列（= info-500） */
  --chart-color-3: #52c41a;   /* 第三系列（= success-500） */
  --chart-color-4: #faad14;   /* 第四系列（= warning-500） */
  --chart-color-5: #722ed1;   /* 第五系列（可视化专用补充色，UI 界面禁用） */
}
```

**使用规约**：
- ECharts `color` 配置必须传 `['var(--chart-color-1)', ..., 'var(--chart-color-5)']`（或从 shared-tokens 读取后注入）
- 系列数 > 5 时循环使用色板，并提高系列间区分度（虚线/面积填充等）
- 图表文字/网格线用 `--color-text-secondary` / `--color-border-light`，同样禁硬编码

## 五、圆角系统

```css
:root {
  --radius-none:   0;
  --radius-sm:      4px;    /* 后台输入框、表格 */
  --radius-base:    6px;    /* 后台按钮、卡片 */
  --radius-md:      8px;    /* H5 卡片、按钮 */
  --radius-lg:      12px;   /* 官网卡片、Modal */
  --radius-xl:      16px;   /* 大卡片、Sheet */
  --radius-2xl:     24px;   /* 官网 Hero 特殊 */
  --radius-full:    9999px; /* 圆形（头像、标签） */
}

/* 后台覆盖 */
[data-app="admin"] {
  --radius-base: 4px;
  --radius-md:   6px;
}

/* 官网覆盖 */
[data-app="site"] {
  --radius-md: 12px;
  --radius-lg: 16px;
}
```

#### 与 PRD D1.6.2 主题变量的关系（2026-09 裁决，消解 8px/6px 基准冲突）

```css
:root {
  --border-radius-base: 8px;   /* PRD D1.6.2 预置主题变量（商家可配），默认 = --radius-md（H5 亲和圆角） */
}
```

- `--border-radius-base`（D1.6.2，scope=global）是**商家主题配置入口**，默认 8px，语义等同本规范的 `--radius-md`（H5 卡片/按钮）
- `--radius-base`（本规范，6px）是**端内设计 token**，指后台按钮/卡片的圆角，两者命名相近但体系不同，**禁止混用**
- 商家主题只作用于 H5/官网消费者侧；后台（admin）不消费 `--border-radius-base`，固定按 §1.2 用 6px 档（`[data-app="admin"]` 覆盖）

## 六、阴影系统

```css
:root {
  /* 无阴影 */
  --shadow-none: none;

  /* 轻阴影：H5 卡片、按钮 hover */
  --shadow-sm: 0 1px 2px rgba(0, 0, 0, 0.06), 0 1px 3px rgba(0, 0, 0, 0.04);

  /* 中阴影：H5 弹窗、后台卡片 hover */
  --shadow-md: 0 2px 8px rgba(0, 0, 0, 0.08), 0 1px 4px rgba(0, 0, 0, 0.04);

  /* 大阴影：Modal、Drawer */
  --shadow-lg: 0 8px 24px rgba(0, 0, 0, 0.12), 0 2px 8px rgba(0, 0, 0, 0.06);

  /* 特大阴影：官网 Hero、浮窗 */
  --shadow-xl: 0 16px 48px rgba(0, 0, 0, 0.16), 0 4px 16px rgba(0, 0, 0, 0.08);

  /* 主色阴影：主按钮 hover */
  --shadow-primary: 0 4px 12px rgba(255, 107, 107, 0.3);
}
```

**使用规约**：
- H5：默认用 `shadow-sm`，弹窗用 `shadow-md`
- 后台：默认无阴影，hover 用 `shadow-sm`
- 官网：Hero 区用 `shadow-xl`，卡片用 `shadow-md`

## 七、按钮规范

### 7.1 按钮类型

| 类型 | 背景 | 文字 | 边框 | 用途 |
|---|---|---|---|---|
| Primary | `--color-primary-500` | `--color-text-inverse` | 无 | 主操作（提交/下单/支付） |
| Secondary | `--color-bg-card` | `--color-primary-500` | `1px solid --color-primary-500` | 辅助操作（取消） |
| Default | `--color-bg-card` | `--color-text-primary` | `1px solid --color-border-base` | 默认操作 |
| Danger | `--color-error-500` | `--color-text-inverse` | 无 | 删除危险操作 |
| Ghost | transparent | `--color-primary-500` | 无 | 链接式按钮 |
| Disabled | `--color-gray-100` | `--color-text-tertiary` | 无 | 禁用态 |

### 7.2 按钮尺寸

| 尺寸 | 高度 | padding | 字号 | 用途 |
|---|---|---|---|---|
| Small | 28px | `4px 12px` | `--font-size-sm` | 后台表格内 |
| Medium | 36px | `8px 16px` | `--font-size-base` | 后台默认 |
| Large | 44px | `12px 24px` | `--font-size-md` | H5 主按钮 |
| Block | 48px | `12px 24px` | `--font-size-md` | H5 全宽按钮（下单/支付） |

### 7.3 按钮状态

```css
.btn-primary {
  background: var(--color-primary-500);
  color: var(--color-text-inverse);
  transition: all 0.2s;
}
.btn-primary:hover:not(:disabled) {
  background: var(--color-primary-600);
  box-shadow: var(--shadow-primary);
}
.btn-primary:active:not(:disabled) {
  background: var(--color-primary-700);
  transform: translateY(1px);
}
.btn-primary:disabled {
  background: var(--color-primary-100);
  color: var(--color-text-tertiary);
  cursor: not-allowed;
}
```

## 八、表单规范

### 8.1 输入框

| 属性 | H5 | 后台 |
|---|---|---|
| 高度 | 44px | 32px |
| 字号 | 15px | 13px |
| padding | `8px 12px` | `4px 8px` |
| 圆角 | `--radius-md` (8px) | `--radius-sm` (4px) |
| 边框 | `1px solid --color-border-base` | 同 |
| Focus 边框 | `1px solid --color-primary-500` | 同 |
| 错误边框 | `1px solid --color-error-500` | 同 |
| 占位符色 | `--color-text-tertiary` | 同 |

### 8.2 表单布局

- H5：单列布局，每项上下间距 `16px`
- 后台：标签在左（宽度 `120px`），输入在右，行间距 `16px`
- 官网联系表单：单列，间距 `16px`

### 8.3 校验反馈

- 错误：输入框下方红字 `--color-error-500`，字号 `--font-size-sm`
- 成功：输入框右侧绿色对勾图标
- 校验时机：`onBlur`（失焦时），不要 `onChange` 实时校验

## 十一、动效规范

### 11.1 过渡时长

```css
:root {
  --duration-fast:    150ms;   /* 按钮 hover/active */
  --duration-normal:  200ms;   /* 弹窗、抽屉 */
  --duration-slow:    300ms;   /* 页面转场 */
  --duration-slower:  500ms;   /* 官网滚动动画 */
}
```

### 11.2 缓动函数

```css
:root {
  --ease-in:       cubic-bezier(0.4, 0, 1, 1);      /* 入场 */
  --ease-out:      cubic-bezier(0, 0, 0.2, 1);     /* 出场 */
  --ease-in-out:   cubic-bezier(0.4, 0, 0.2, 1);   /* 双向 */
  --ease-bounce:   cubic-bezier(0.34, 1.56, 0.64, 1); /* 弹性 */
}
```

### 11.3 各端动效约束

| 端 | 动效 | 约束 |
|---|---|---|
| H5 | 页面转场（slide）、弹窗（fade+scale）、按钮（scale） | 不超过 300ms，GPU 加速（transform/opacity） |
| 后台 | 无动效（效率优先） | 仅 hover 颜色过渡 150ms |
| 官网 | Hero 动画、滚动进入、视差 | GSAP，时长 500-800ms，`prefers-reduced-motion` 自动禁用 |

### 11.4 prefers-reduced-motion

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 十八、主题配置实现

### 18.1 商家自定义主题

后台"商城主题配置"页允许商家修改主色，所有用 `--color-primary-*` 的地方自动跟随变化。

**实现原理**：通过 HSL 色彩空间生成色阶

```typescript
// packages/shared-tokens/src/theme.ts
import { hexToHsl, hslToHex } from './color-utils';

/**
 * 根据主色生成 10 级色阶（键名 50~900，对齐 §2.1 定义）
 * HSL 色彩空间调整亮度 L
 */
export function generateColorScale(primaryHex: string): Record<string, string> {
  const [h, s, l] = hexToHsl(primaryHex);
  // 键名与 §2.1 色阶一一对应：50/100/200/.../900 共 10 档（禁用 0~1000 旧口径）
  // 500 = 主色本体（保留原始明度 l），其余档位按默认色阶实测间距偏移
  const steps: Array<[string, number]> = [
    ['50', l + 26], ['100', l + 23], ['200', l + 18], ['300', l + 11], ['400', l + 4],
    ['500', l],
    ['600', l - 12], ['700', l - 22], ['800', l - 30], ['900', l - 38],
  ];
  const scale: Record<string, string> = {};
  steps.forEach(([key, level]) => {
    scale[key] = hslToHex(h, s, Math.max(0, Math.min(100, level)));
  });
  return scale;
}

/**
 * 应用主题到 CSS 变量
 */
export function applyTheme(scope: 'global' | 'h5' | 'site', vars: Record<string, string>) {
  Object.entries(vars).forEach(([key, value]) => {
    document.documentElement.style.setProperty(key, value);
  });
}
```

### 18.2 预设主题

提供 5 套预设主题，商家一键套用：

| 主题名 | 主色 | 适用 |
|---|---|---|
| 珊瑚红（默认） | #ff6b6b | 通用/服装/美妆 |
| 商务蓝 | #1890ff | 数码/家电 |
| 自然绿 | #52c41a | 生鲜/农产品 |
| 高贵紫 | #722ed1 | 珠宝/奢侈品 |
| 稳重橙 | #fa8c16 | 食品/餐饮 |

> **预设主题只定义主色**。完整变量集 = `generateColorScale(primaryHex)` 色阶（§18.1）+ D1.6.2 预置变量默认值，由幂等 seed 脚本写入 `site_themes` 表，落库时机与套用接口见 **PRD D1.6.4**（1b 期 plan-14+ 实施）。shared-tokens 实现时内置 5 套预设的完整变量集常量，供前端预览与后端 seed 双端复用（单一事实源：常量由本表主色清单生成）。

## 二十一、Z-index 层级规范

> 全局 Z-index 层级表，避免层叠冲突。所有组件必须使用本表定义的 Z-index 值，禁自由硬编码。

### 21.1 层级表

| 层级 | Z-index | 用途 | 示例 |
|---|---|---|---|
| 基础 | 0 | 普通文档流 | 页面内容 |
| 浮层 | 10 | Tabbar / 固定头 | H5 底部 Tabbar |
| 吸顶 | 20 | 吸顶搜索栏 / 筛选条 | 商品列表吸顶筛选 |

| 弹窗 | 1200 | Modal / Dialog | 确认弹窗 |
| Toast | 1300 | Toast / 通知 | 加购成功提示 |
| Loading | 9999 | 全屏 Loading / 骨架遮罩 | 下单 Loading |
| 引导 | 10000 | 新手引导 / 蒙层 | 首次使用引导 |

```css
:root {

  --z-tabbar: 10;
  --z-sticky: 20;
  --z-dropdown: 1000;
  --z-drawer: 1100;
  --z-modal: 1200;
  --z-toast: 1300;
  --z-loading: 9999;

```

### 21.3 规约

- 禁硬编码 `z-index: 999`，必须用 `var(--z-modal)` 等变量
- 嵌套浮层（如 Modal 内 Dropdown）：Modal 用 `--z-modal`，内部 Dropdown 用 `--z-dropdown` + 父级 stacking context 自然隔离
- 新增层级必须先更新本表，否则视为违规

- 切换页码时：表格内容区显示骨架屏（不是全屏 Loading）
- 切换条数时：同上
- 行内操作 Loading：当前行 + 50% 透明度遮罩

### 23.5 排序与筛选

- 排序：表头点击切换（无序 → 升序 → 降序 → 无序）
- 筛选：表头筛选项（Dropdown），多选用 Checkbox
- 排序 + 筛选状态记忆到 URL Query（刷新不丢失）

## 二十四、a11y 可访问性量化标准

### 24.1 对比度（WCAG AA 强制）

| 元素 | 对比度要求 | 测量工具 |
|---|---|---|
| 正文文本（< 18px） | ≥ 4.5:1 | Lighthouse / axe-core |
| 大文本（≥ 18px 或 14px 粗体） | ≥ 3:1 | 同上 |
| 图标 / 边框 | ≥ 3:1 | 同上 |
| 禁用状态文本 | ≥ 2:1 | 同上 |

**禁用配色组合**：
- 白底 + `--color-gray-400`（文本）→ 对比度不足
- 主色 `#ff6b6b` + 白底（正文）→ 对比度 3.5:1，不足

### 24.2 键盘导航

| 键位 | 行为 |
|---|---|
| Tab | 焦点流转（DOM 顺序） |
| Shift+Tab | 反向流转 |
| Enter / Space | 激活当前元素（按钮 / 链接） |
| Esc | 关闭当前浮层（Modal / Drawer / Dropdown） |
| ↑↓ | 列表 / 表格行选择 |
| ←→ | Tabbar / 轮播图切换 |

### 24.3 焦点样式（focus-visible）

```css
:focus-visible {
  outline: 2px solid var(--color-primary-500);
  outline-offset: 2px;
}
```

- 禁用 `outline: none`（除非有替代焦点样式）
- 焦点必须可见（对比度 ≥ 3:1）

### 24.4 ARIA 语义

| 场景 | ARIA 属性 |
|---|---|
| 按钮 | `role="button"` + `aria-label`（如无文本） |
| 图标按钮 | `aria-label` 必填（如"关闭" / "搜索"） |
| Modal | `role="dialog"` + `aria-modal="true"` + `aria-labelledby` |
| Toast | `role="status"` + `aria-live="polite"` |
| 错误 Toast | `role="alert"` + `aria-live="assertive"` |
| 加载 | `role="progressbar"` + `aria-valuenow/min/max` |
| 表单错误 | `aria-invalid="true"` + `aria-describedby` 指向错误信息 |
| Tab 切换 | `role="tablist"` + `role="tab"` + `aria-selected` |

### 24.5 屏幕阅读器适配

| 元素 | 适配方式 |
|---|---|
| 图片 | `alt` 属性（装饰图用 `alt=""`） |
| 链接 | 文本或 `aria-label`（禁"点击这里"） |
| 表单 | `<label>` 关联（禁 `placeholder` 替代 label） |
| 跳过导航 | 首个可聚焦元素加"跳到主内容"链接 |
| 标题层级 | `<h1>` ~ `<h6>` 不跳级 |

### 24.6 验证工具

| 工具 | 用途 | 集成方式 |
|---|---|---|
| Lighthouse | 综合评分（目标 ≥ 90） | CI 跑 |
| axe-core | 单元级 a11y 测试 | vitest + @axe-core/playwright |
| @axe-core/playwright | E2E a11y 测试 | E2E 跑 |
| better-interface skill | AI 审查 a11y | 主 Agent 调用 |

### 24.7 强制要求

- Lighthouse a11y 评分 ≥ 90 才能合并 PR
- axe-core 0 error 才能合并 PR
- 键盘导航必跑 E2E（Tab 流 + Esc 关闭）
- 每个图标按钮必须有 `aria-label`
