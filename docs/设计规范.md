# LiteShop 设计规范（Design System）

> 本文件是 LiteShop 全端（H5 商城 / 管理后台 / 官网 / 共享组件）的统一视觉规范。
> 所有 Agent 在写 UI 时必须遵循本规范。本规范作为 PRD 附录 D1.6 的扩展，与 PRD 配套使用。
> 配套：`packages/shared-tokens/`（实现层）、Storybook（可视化文档）

---

## 一、设计理念

### 1.1 产品定位

LiteShop 是面向中小商家的轻量级低代码商城系统。视觉风格应该：

- **现代简洁**：不堆砌装饰，留白充足，信息密度适中
- **商家友好**：后台高效操作，H5 信任感强，官网专业感
- **可配置**：商家能通过主题配置快速换色，不需要改代码
- **跨端一致**：H5 / 官网 / 后台共享同一套 Design Tokens，品牌感统一

### 1.2 三端视觉差异

| 维度 | H5 商城 | 管理后台 | 官网 |
|---|---|---|---|
| 风格 | 活泼、信任、转化导向 | 高效、密集、专业 | 大气、叙事、品牌感 |
| 主色 | 主色 #ff6b6b（珊瑚红） | 同主色 | 同主色 |
| 字号 | 偏大（移动端阅读） | 偏小（信息密集） | 中等 + Hero 大字号 |
| 间距 | 紧凑（屏幕有限） | 紧凑 | 宽松（叙事空间） |
| 圆角 | 8px（亲和） | 6px（专业） | 12px（现代） |
| 阴影 | 轻柔 | 几乎不用 | Hero 区用明显阴影 |
| 动效 | 转场过渡，不过度 | 无（效率优先） | 滚动动画 + Hero 视差 |

## 二、色彩系统

### 2.1 品牌主色

主色 `#ff6b6b`（珊瑚红），传达热情、活力、消费欲望。生成 11 级色阶：

```css
:root {
  --color-primary-50:  #fff1f1;   /* 最浅，背景/禁用态 */
  --color-primary-100: #ffe0e0;
  --color-primary-200: #ffc6c6;
  --color-primary-300: #ffa3a3;
  --color-primary-400: #ff8080;
  --color-primary-500: #ff6b6b;   /* 主色，按钮/链接/选中态 */
  --color-primary-600: #e54545;   /* hover */
  --color-primary-700: #c93030;   /* active */
  --color-primary-800: #a82828;
  --color-primary-900: #8a2020;   /* 最深 */
  --color-primary: var(--color-primary-500);  /* 别名 */
}
```

**使用场景**：
- 500：主按钮、链接、选中态、Tabbar 选中
- 600：主按钮 hover
- 700：主按钮 active
- 50：主色背景（如优惠券标签底色）、禁用态背景

### 2.2 功能色

## 六、阴影系统

```css
:root {
  /* 无阴影 */
  --shadow-none: none;

  /* 轻阴影：H5 卡片、按钮 hover */
  --shadow-sm: 0 1px 2px rgba(0, 0, 0, 0.06), 0 1px 3px rgba(0, 0, 0, 0.04);

  /* 中阴影：H5 弹窗、后台卡片 hover */
  --shadow-md: 0 2px 8px rgba(0, 0, 0, 0.08), 0 1px 4px rgba(0, 0, 0, 0.04);

  /* 大阴影：Modal、Drawer */
  --shadow-lg: 0 8px 24px rgba(0, 0, 0, 0.12), 0 2px 8px rgba(0, 0, 0, 0.06);

  /* 特大阴影：官网 Hero、浮窗 */
  --shadow-xl: 0 16px 48px rgba(0, 0, 0, 0.16), 0 4px 16px rgba(0, 0, 0, 0.08);

  /* 主色阴影：主按钮 hover */
  --shadow-primary: 0 4px 12px rgba(255, 107, 107, 0.3);

```

**使用规约**：
- H5：默认用 `shadow-sm`，弹窗用 `shadow-md`
- 后台：默认无阴影，hover 用 `shadow-sm`
- 官网：Hero 区用 `shadow-xl`，卡片用 `shadow-md`

## 七、按钮规范

### 7.1 按钮类型

| 类型 | 背景 | 文字 | 边框 | 用途 |
|---|---|---|---|---|
| Primary | `--color-primary-500` | `--color-text-inverse` | 无 | 主操作（提交/下单/支付） |
| Secondary | `--color-bg-card` | `--color-primary-500` | `1px solid --color-primary-500` | 辅助操作（取消） |
| Default | `--color-bg-card` | `--color-text-primary` | `1px solid --color-border-base` | 默认操作 |
| Danger | `--color-error-500` | `--color-text-inverse` | 无 | 删除危险操作 |
| Ghost | transparent | `--color-primary-500` | 无 | 链接式按钮 |
| Disabled | `--color-gray-100` | `--color-text-tertiary` | 无 | 禁用态 |

### 7.2 按钮尺寸

| 尺寸 | 高度 | padding | 字号 | 用途 |
|---|---|---|---|---|
| Small | 28px | `4px 12px` | `--font-size-sm` | 后台表格内 |
| Medium | 36px | `8px 16px` | `--font-size-base` | 后台默认 |
| Large | 44px | `12px 24px` | `--font-size-md` | H5 主按钮 |
| Block | 48px | `12px 24px` | `--font-size-md` | H5 全宽按钮（下单/支付） |

### 7.3 按钮状态

```css
.btn-primary {
  background: var(--color-primary-500);
  color: var(--color-text-inverse);
  transition: all 0.2s;
}
.btn-primary:hover:not(:disabled) {
  background: var(--color-primary-600);
  box-shadow: var(--shadow-primary);
}
.btn-primary:active:not(:disabled) {
  background: var(--color-primary-700);
  transform: translateY(1px);
}
.btn-primary:disabled {
  background: var(--color-primary-100);
  color: var(--color-text-tertiary);
  cursor: not-allowed;
}
```

## 八、表单规范

### 8.1 输入框

| 属性 | H5 | 后台 |
|---|---|---|
| 高度 | 44px | 32px |
| 字号 | 15px | 13px |
| padding | `8px 12px` | `4px 8px` |
| 圆角 | `--radius-md` (8px) | `--radius-sm` (4px) |
| 边框 | `1px solid --color-border-base` | 同 |
| Focus 边框 | `1px solid --color-primary-500` | 同 |
| 错误边框 | `1px solid --color-error-500` | 同 |
| 占位符色 | `--color-text-tertiary` | 同 |

### 8.2 表单布局

- H5：单列布局，每项上下间距 `16px`
- 后台：标签在左（宽度 `120px`），输入在右，行间距 `16px`
- 官网联系表单：单列，间距 `16px`

### 8.3 校验反馈

- 错误：输入框下方红字 `--color-error-500`，字号 `--font-size-sm`
- 成功：输入框右侧绿色对勾图标
- 校验时机：`onBlur`（失焦时），不要 `onChange` 实时校验

## 十一、动效规范

### 11.1 过渡时长

```css
:root {
  --duration-fast:    150ms;   /* 按钮 hover/active */
  --duration-normal:  200ms;   /* 弹窗、抽屉 */
  --duration-slow:    300ms;   /* 页面转场 */
  --duration-slower:  500ms;   /* 官网滚动动画 */
}
```

### 11.2 缓动函数

```css
:root {
  --ease-in:       cubic-bezier(0.4, 0, 1, 1);      /* 入场 */
  --ease-out:      cubic-bezier(0, 0, 0.2, 1);     /* 出场 */
  --ease-in-out:   cubic-bezier(0.4, 0, 0.2, 1);   /* 双向 */
  --ease-bounce:   cubic-bezier(0.34, 1.56, 0.64, 1); /* 弹性 */
}
```

### 11.3 各端动效约束

| 端 | 动效 | 约束 |
|---|---|---|
| H5 | 页面转场（slide）、弹窗（fade+scale）、按钮（scale） | 不超过 300ms，GPU 加速（transform/opacity） |
| 后台 | 无动效（效率优先） | 仅 hover 颜色过渡 150ms |
| 官网 | Hero 动画、滚动进入、视差 | GSAP，时长 500-800ms，`prefers-reduced-motion` 自动禁用 |

### 11.4 prefers-reduced-motion

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

## 十二、响应式断点

### 12.1 断点定义（Tailwind v4 约定）

```css
:root {
  --breakpoint-sm: 640px;    /* 手机横屏 */
  --breakpoint-md: 768px;    /* 平板竖屏 */
  --breakpoint-lg: 1024px;   /* 平板横屏/小桌面 */
  --breakpoint-xl: 1280px;  /* 桌面 */
  --breakpoint-2xl: 1536px; /* 大桌面 */
}
```

### 12.2 H5 适配

- 设计宽度：375px（iPhone 标准）
- 适配范围：320px - 430px
- 单位：vw / rem（不用 px 固定宽度）
- 安全区域：`padding-bottom: env(safe-area-inset-bottom)`

### 12.3 官网响应式

| 断点 | 布局变化 |
|---|---|
| < sm (640px) | 单列、汉堡菜单、Hero 字号缩小 |
| sm - md | 双列 Features、Footer 双列 |
| md - lg | 三列 Features、Navbar 完整显示 |
| lg - xl | 四列 Features、Hero 左右分栏 |
| > xl | 最大宽度 1280px 居中、5xl 字号 Hero |

### 12.4 后台

- 最小宽度：1280px
- 低于 1280px 出现横向滚动
- 不做移动端适配（后台 PC 专用）

## 十八、主题配置实现

### 18.1 商家自定义主题

后台"商城主题配置"页允许商家修改主色，所有用 `--color-primary-*` 的地方自动跟随变化。

**实现原理**：通过 HSL 色彩空间生成色阶

```typescript
// packages/shared-tokens/src/theme.ts
import { hexToHsl, hslToHex } from './color-utils';

/**
 * 根据主色生成 11 级色阶
 * HSL 色彩空间调整亮度 L
 */
export function generateColorScale(primaryHex: string): Record<string, string> {
  const [h, s, l] = hexToHsl(primaryHex);
  const levels = [95, 90, 80, 70, 60, 50, 45, 40, 35, 30, 25];
  const scale: Record<string, string> = {};
  levels.forEach((level, i) => {
    scale[`${i * 100}`] = hslToHex(h, s, level);
  });
  return scale;
}

/**
 * 应用主题到 CSS 变量
 */
export function applyTheme(scope: 'global' | 'h5' | 'site', vars: Record<string, string>) {
  Object.entries(vars).forEach(([key, value]) => {
    document.documentElement.style.setProperty(key, value);
  });
}
```

提供 5 套预设主题，商家一键套用：
