## 当前目标

Stitch 页面/组件/交互还原与全栈减负重构，保持现有 API 和业务功能。计划：[plan-38](../plans/plan-38.md)、[plan-39](../plans/plan-39.md)。

## 已核实现状

- H5/Admin/Site 都已有代码，后端并存数据库与内存开发路径；页面存在不等于完整交付。
- H5 图像、空数据及交互需修正；Admin 有虚构身份、固定日期和无效入口。
- 后台四重继承 facade、商品列表多余规格加载是明确重构对象。
- 3D 只有配置/降级与 CSS/静态展示，没有真实模型渲染器；依赖、模型和展示位置仍需具体确认。
- UI Kit 尚未按真实调用方完成迁移，本轮不强制全量替换。
- PRD 四分片已合并为完整 [PRD](PRD-v1.3.md)，保留分期修订及 D/E 附录；历史交接已归档，操作手册保留根目录版本。

## 实施顺序

1. H5：设计还原、图片/空态/交互、无用兼容入口。
2. Backend：领域服务依赖、列表查询，保留权限/事务/幂等。
3. Admin：框架、表格、表单、搭建器及兼容聚合清理。
4. Site：3D 回退、设备变化、动画生命周期。
5. 独立类型/lint/测试/构建与浏览器操作验收。

## 当次验证及限制

- 计划建立时尚无本轮代码验收结论，历史测试数字不复用。
- 外网下载、图标安装、浏览器控制的自动审批服务返回 503；图标库安装、高清图与浏览器回归受阻。
- 系统 Python 启动报缺少 `encodings`，正在查找已有运行时；后端测试尚不能称通过。
- 既有环境变量、后端集成测试、E2E 配置及其他 dirty tree 改动保留。

## 能力边界

- 真实支付/短信/物流等供应商、真实数据库端到端、完整 i18n/a11y 不能以演示数据验收。
- 领券、新支付结果路由、物流时间线、凭证上传等按 plan-38 对照后确认。
- 未授权自动发布、推送、生产数据操作或数据库迁移。
