# LiteShop Local Compatibility Skill

This is a local compatibility implementation because no public market source named `better-interface` was available during initialization.

## Review checklist

- Use semantic landmarks, headings, labels, button elements, and accessible names.
- Verify keyboard navigation, visible focus, Escape behavior, and logical tab order.
- Check color contrast, non-color affordances, reduced-motion behavior, and text zoom.
- Check form errors, loading states, empty states, touch target sizing, and responsive overflow.
- Prefer automated checks such as axe-core or Playwright, then inspect the affected UI manually.

Report each issue with severity, location, impact, and a concrete remediation. Do not change application code unless the user asks for fixes.
